
# Windows System Optimizer

## What is this?

A tool that cleans up junk files from your Windows computer. It removes temporary files, browser caches, and old update leftovers that take up space for no reason.

**It will NOT delete your photos, documents, music, or any personal files.**

## What you get

- More free space on your hard drive (usually 5-20GB)
- Slightly faster PC
- Cleaner browser without losing your saved passwords or bookmarks

## Works on

- Windows 7
- Windows 8 / 8.1
- Windows 10
- Windows 11

## How to use (3 steps)

### Step 1: Download

Click the green "Code" button above then "Download ZIP"  
OR  
Download the `SystemOptimizer.bat` file directly

### Step 2: Run as Administrator

Find the downloaded file.  
**Right-click** on it.  
Choose **"Run as Administrator"** (this is important)

### Step 3: Follow what it says on screen

- Press Enter to start
- Say YES or NO to each question (the tool explains each one)
- Wait 2-5 minutes
- Restart your PC when it's done

That's it. No installation. No setup. No registry changes.

## What happens when you run it?

```

1. Checks your current free space
2. Creates a system restore point (safety backup)
3. Cleans temporary files
4. Asks if you want to clear browser caches
5. Cleans Windows update leftovers
6. Rotates old log files
7. Asks if you want to empty recycle bin
8. Flushes DNS and renews IP
9. Shows you how much space was freed

```

## First time user? Do this:

1. Download the file to your desktop
2. Right-click → Run as Administrator
3. Say YES to browser cache (frees space)
4. Say YES to empty recycle bin (if you already checked nothing important is there)
5. Say NO to disk check (unless you have time to wait)
6. Restart your PC

## Will this break my computer?

No. Thousands of people have run this. Here's why it's safe:

- Creates a restore point before doing anything
- Never touches your personal folders (Documents, Desktop, Downloads, Pictures)
- Never changes the registry
- Only uses built-in Windows commands
- Asks you before doing anything permanent

## I ran it. Now what?

Restart your PC. Then use your computer like normal. You should notice:

- More free space shown in This PC
- Browser might open a little faster
- Nothing else changed

## How often should I run this?

- Normal users: Once every 2-3 months
- Heavy browsing/gaming: Once a month
- Low disk space emergency: Right now

## Problems? Fixes:

**"Windows protected your PC" popup**
Click "More info" then "Run anyway"

**"Access denied" errors**
You forgot to right-click and choose "Run as Administrator"

**Script closes immediately**
Same as above - you need admin rights

**Windows Defender blocks it**
It's a false positive because batch files can delete things. The script is open source - you can read every line of code yourself.

## Where are the logs?

After running, open your Desktop → System_Logs folder. There's a text file showing everything that happened.

## Do I need to install anything?

No. The .bat file is the whole program. Delete it when you don't need it. No uninstall required.

## Can I see what the script does before running?

Yes. Right-click the .bat file and choose "Edit". It's plain text. Every command is visible.
